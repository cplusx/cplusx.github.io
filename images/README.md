# Paper Screenshots Directory

Place paper teaser/homepage screenshots in the `papers/` subdirectory.

## Naming Convention

Name your images according to the paper venue and year:

- `cvpr2026-memo.jpg` - MEMO edge detection paper
- `neurips2024-rich-context.jpg` - Rich-context L2I generation
- `iclr2024-video-transfer.jpg` - Video-to-video transfer
- `aaai2023-style-transfer.jpg` - User-controllable style transfer
- `cvprw2023-layoutdiffuse.jpg` - LayoutDiffuse
- `neuripsw2022-head.jpg` - HEAD adversarial detection
- `iccv2021-sign.jpg` - SIGN zero-shot segmentation
- `cvpr2021-style-loss.jpg` - Style-aware loss (ORAL)
- `cvpr2019-qatm.jpg` - QATM template matching
- `icdar2019-text-detection.jpg` - Scene text detection
- `accv2018-image-gps.jpg` - Image-to-GPS verification
- `cvpr2026-homography.jpg` - Multimodal homography estimation
- `cvprw2019-face-manipulation.jpg` - Face manipulation detection
- `preprint-dense-face.jpg` - Dense-Face preprint

## Image Specifications

- **Recommended size**: 300x180px or similar aspect ratio (5:3)
- **Format**: JPG or PNG
- **File size**: Keep under 200KB for fast loading

If you don't have screenshots yet, placeholder images will be shown automatically.
